# Changelog

All notable changes to this project will be documented in this file.

The format is based on [Keep a Changelog](https://keepachangelog.com/en/1.0.0/),
and this project adheres to [Semantic Versioning](https://semver.org/spec/v2.0.0.html).

## [1.0.0] - 2024-03-19

### Added

- Initial public release of ShashinMori App
- Google authentication via Firebase Auth
- Photo upload functionality with tus protocol
- Private photo gallery with responsive grid layout
- Dark/Light theme support with system preference detection
- Multi-platform support (Web, Android)
- Image caching with shimmer loading states
- Real-time upload status polling
- Material Design 3 UI components
- Riverpod state management
- GoRouter navigation system
- Firebase configuration via `.env` file

### Features

- Sign in with Google
- Upload photos from web and Android
- View personal photo gallery
- Responsive design for different screen sizes
- Progress tracking for uploads
- Beautiful UI with animations

### Security

- Firebase Auth for secure authentication
- HTTPS support for production deployments
